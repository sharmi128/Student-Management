Smart College Management System

Java 17 + Maven desktop project for student, teacher, attendance, fees, and notices management.

Core Modules

  • Student module
  • Teacher module
  • Attendance module
  • Fees and notices

Run Locally

  • Use Java 17
  • Run: mvn clean package
  • Main class: com.smartcollege.erp.App

  • This index.html enables browser preview.
  • Push to main branch.
  • Enable Pages from branch: main, folder: /(root).
